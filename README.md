# Yfometris – Stylometric Analysis Software
Yfometris is a historical stylometric analysis application developed by Theodoros Doganis in Visual Basic .NET and completed in 2011.The software supports the management and analysis of electronic text corpora, metadata-based subcorpus selection, computation of stylometric measures, and export of analysis results to Microsoft Excel.
This archival release includes the original Visual Studio project, source code, historical build artifacts, and the separate Testform application used for testing stylometric calculations.

The application was originally developed under the name "Text Analysis". The name "Yfometris" is adopted for its public archival release.

The original source code has been preserved without modification. No new build or compatibility testing has been performed for this release.

Historical requirements: Windows XP/Vista/7, .NET Framework 4.0, and Microsoft Office with Excel interoperability.

Repository Structure

This repository contains the original source code of Yfometris, a stylometric analysis application developed in Visual Basic .NET and completed in 2011.

The repository is organized into three main components:

1. Original Source Archive

Yfometris_2011_Source_Archive.zip

The complete archival distribution, containing both Visual Studio projects and accompanying documentation. It is preserved as a standalone package for historical reference and long-term preservation.

2. Yfometris — Main Application

/Yfometris/

Contains the original Visual Studio project and source code of the main application, originally named Text Analysis.

This application provides electronic text corpus management, metadata-based subcorpus selection, stylometric analysis, and export of results to Microsoft Excel.

3. Testform — Testing Application

/Testform/

Contains a separate Visual Studio project developed to test and verify individual stylometric calculations.

Testform was used during development to validate the mathematical implementation of the stylometric measures independently of the main application's corpus management functionality.

Historical Preservation

Both projects are preserved in their original form, including their original file names, form names, internal identifiers, and project structure.

No refactoring, modernization, or compatibility updates have been performed for this archival release.

The official public name of the software is Yfometris, although the original application retains the name Text Analysis internally.
