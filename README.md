# Yfometris – Stylometric Analysis Software
Yfometris is a historical stylometric analysis application developed by Theodoros Doganis in Visual Basic .NET and completed in 2011.The software supports the management and analysis of electronic text corpora, metadata-based subcorpus selection, computation of stylometric measures, and export of analysis results to Microsoft Excel.
This archival release includes the original Visual Studio project, source code, historical build artifacts, and the separate Testform application used for testing stylometric calculations.

The application was originally developed under the name "Text Analysis". The name "Yfometris" is adopted for its public archival release.

The original source code has been preserved without modification. No new build or compatibility testing has been performed for this release.

Historical requirements: Windows XP/Vista/7, .NET Framework 4.0, and Microsoft Office with Excel interoperability.
